| 2026-07-28 | Treat canonical serialization bytes plus LF as part of ledger/profile integrity, not merely parsed JSON equivalence | Whitespace, CRLF, key-order, and escaping alternatives otherwise mutate observed evidence without breaking semantic replay | Accept any JSON that decodes to the same object |
